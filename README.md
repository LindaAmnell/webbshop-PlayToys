Summer Toy Webshop Play Toys
This is an individual project created as part of a course assignment. The goal was to build a fully functional e-commerce website that sells summer toys. The application was developed using React, React Router (with HashRouter), and Zustand for state management. The webshop allows customers to browse a product catalog, add items to the shopping cart, and complete purchases.

Key features include:

Responsive Design: The app is fully responsive and optimized for both desktop and mobile screens.

Admin Functionality: Admin users can log in to add, remove, and modify products in the shop.

Smart Search and Sorting: Customers can search for products by name or category, and sort them by price or name.

Shopping Cart: Customers can add products to the cart, view their total price, and modify quantities.
